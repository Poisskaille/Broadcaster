## Shortcuts to know

- **Escape** : Open Settings
- **R** : Fast reload application *(under a seconds)* Useful if sounds does not match the video.
- **T** : Show / Hide Cursor.
- **F12** : Screenshot, saved in special folder.
- **F10** : Save clip *(not perfect at the moment)* , also stocked in a special folders

Shortcuts are configurable.
